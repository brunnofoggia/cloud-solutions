# Informations

## Creating a new solution

This is a guide to create a new solution to be used with the factory. A solution can be any service that you can find in a cloud provider, like storage, events management, secrets management, databases, etc.

### Objective

List archives that should be updated to list the new solution.

### Archive List

- `src/common/config.ts`
- `src/common/interfaces/solutions.interface.ts`
- `src/solutions.factory.ts`
